# 계좌 화면 데모

보내주신 화면 이미지를 그대로 표시하고, 지정한 부분을 누르면 다음 화면으로 이동하는 정적 웹 앱입니다. 실제 은행 서비스가 아니며 로그인, 송금, 계좌 조회 기능은 없습니다.

## 아이폰에서 실행하기 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다. 화면 이미지에는 이름과 계좌번호가 보이므로 공개 저장소에 올리기 전에 민감한 정보를 가리세요. GitHub Pages의 일반 공개 URL에서는 누구나 화면 이미지를 볼 수 있습니다.
2. `index.html`과 `assets` 폴더를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, `main`, `/ (root)`를 선택해 저장합니다.
4. 표시된 `https://사용자명.github.io/저장소명/` 주소를 아이폰 Safari에서 엽니다. Safari 공유 메뉴의 **홈 화면에 추가**를 선택하면 아이콘처럼 실행할 수 있습니다.

이미 이전 버전을 올렸다면 저장소의 **Add file → Upload files**에서 새 `index.html`과 `assets` 폴더의 파일들을 업로드해 같은 이름의 파일을 교체한 뒤 **Commit changes**를 누릅니다. 이전의 `assets/icon.jpg`는 더 이상 사용하지 않습니다.

화면 이동: 첫 화면 **211,000원** → 거래내역조회. 첫 화면의 노란 **이체** → 이체 화면. 이체 화면의 왼쪽 **〈 이체** 또는 상단 **홈 아이콘**을 누르면 첫 화면으로 돌아갑니다. 이체 화면은 이미지 기반 안내 화면으로 실제 계좌번호 입력이나 송금 기능은 없습니다.

## 거래내역 재구성

제공된 스크린샷의 내역 42건을 시간 역순으로 표시합니다. 2026.09.25 19:44:40부터 20:30:57까지의 3만 원 입금 6건과 2026.09.26 00:36:27의 15만 원 출금, 02:11:51의 3만 원 출금은 제외했습니다. 제외 금액은 입금과 출금 각각 18만 원이라 최종 잔액은 211,000원입니다. 거래 중간 잔액도 순서대로 다시 계산했습니다.

오민성 53,000원 입금은 화면에서 거래시각이 잘려 있어 `09.20~21 시각 미확인`으로 표시합니다. 정확한 시각은 원본 화면에서 확인해야 합니다.

이 화면은 개인용 재구성 자료이며 은행이 발급한 거래내역이 아닙니다. 게시된 화면 이미지의 계좌번호는 원본 스크린샷에 포함되어 있습니다.

아이폰 홈 화면 아이콘은 노란색 아이콘 부분만 재구성한 `assets/icon.png`입니다. 이전 버전을 홈 화면에 추가했다면 기존 아이콘을 삭제하고 새 주소를 다시 추가하세요. 화면이 그대로 보이면 Safari에서 새로고침하세요.

이미지와 고정된 데이터 기반 화면이며 실제 은행 앱의 데이터와 연결되지 않습니다.
