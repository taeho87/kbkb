# 계좌 화면 데모

보내주신 화면 이미지를 그대로 표시하고, 지정한 부분을 누르면 다음 화면으로 이동하는 정적 웹 앱입니다. 실제 은행 서비스가 아니며 로그인, 송금, 계좌 조회 기능은 없습니다.

## 아이폰에서 실행하기 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다. 화면 이미지에는 이름과 계좌번호가 보이므로 공개 저장소에 올리기 전에 민감한 정보를 가리세요. GitHub Pages의 일반 공개 URL에서는 누구나 화면 이미지를 볼 수 있습니다.
2. `index.html`과 `assets` 폴더를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, `main`, `/ (root)`를 선택해 저장합니다.
4. 표시된 `https://사용자명.github.io/저장소명/` 주소를 아이폰 Safari에서 엽니다. Safari 공유 메뉴의 **홈 화면에 추가**를 선택하면 아이콘처럼 실행할 수 있습니다.

화면 이동: 첫 화면 **211,000원** → 거래내역 **고태호 / -30,000원** → 상세 **확인** → 거래내역. 상단의 뒤로 가기와 X도 동작합니다.

이미지 기반 화면이므로 표시된 시각과 잔액은 고정되어 있습니다. 실제 은행 앱의 데이터와 연결되지 않습니다.
